# Contributing to Constellation25

We are a closed-loop sovereign mesh. To contribute:
1. Fork the repo (Internal Fork #10,001).
2. Create a branch: `git checkout -b feature/your-agent-name`.
3. Run the TotalRecall validator: `python3 modules/totalrecall_mesh/orchestrator/orchestrator.py`.
4. Submit a pull request to the **main** branch.

*Note: All contributions are hashed and stored in the TotalRecall forensic vault.*
