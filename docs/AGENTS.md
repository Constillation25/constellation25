# Constellation25 - Agent Reference

## Agent Architecture

Each planetary agent is a specialized AI worker with:
- Dedicated task queue
- Isolated execution context
- Forensic logging
- BioAuth integration for critical tasks
- ReadDo compatible

## Agent Details

### 🌍 Earth — Code Structure
**Role**: Foundation and scaffolding
**Triggers**: new project, init, scaffold, create
**Output**: Project structure, boilerplate, templates

### 🌙 Moon — Bug Fixes
**Role**: Syntax errors and debugging
**Triggers**: bug, error, fix, broken, crash
**Output**: Fixed code, debug reports

### ☀️ Sun — Performance
**Role**: Speed and optimization
**Triggers**: slow, optimize, performance, fast
**Output**: Optimized code, profiling reports

### ☿ Mercury — Testing
**Role**: Unit tests and coverage
**Triggers**: test, coverage, jest, pytest
**Output**: Test suites, coverage reports

### ♀ Venus — Regression
**Role**: Integration and regression tests
**Triggers**: regression, integration, e2e
**Output**: Test scenarios, CI configs

### ♂ Mars — Security
**Role**: Vulnerability scanning
**Triggers**: security, auth, vuln, hack, exploit
**Output**: Security reports, patches
**BioAuth**: Required for critical patches

### ♃ Jupiter — Documentation
**Role**: Docs and analysis
**Triggers**: docs, readme, explain, analyze
**Output**: Markdown docs, README files

### ♄ Saturn — Refactoring
**Role**: Code modernization
**Triggers**: refactor, clean, modernize, legacy
**Output**: Refactored code, migration guides

### ♅ Uranus — NLP
**Role**: Natural language processing
**Triggers**: summarize, parse, extract, nlp
**Output**: Summaries, parsed data

### ♆ Neptune — Deduplication
**Role**: Code consolidation
**Triggers**: duplicate, merge, consolidate, dedup
**Output**: Deduplicated codebase

### 🦢 Cygnus — AI/ML
**Role**: Model integration
**Triggers**: ai, ml, model, llm, train
**Output**: ML pipelines, model configs

### 🏹 Orion — UI/UX
**Role**: Frontend development
**Triggers**: ui, ux, frontend, css, design
**Output**: HTML/CSS/JS components

### 🌌 Andromeda — API
**Role**: API and integrations
**Triggers**: api, webhook, integration, endpoint
**Output**: API specs, integration code

### ✨ Pleiades — Environment
**Role**: Dependencies and packages
**Triggers**: install, package, dependency, env
**Output**: Package configs, lockfiles

### ⭐ Sirius — Deployment
**Role**: Deploy and scaling
**Triggers**: deploy, push, vercel, docker, prod
**Output**: Deploy scripts, configs
**BioAuth**: Required for production deploys

### 🐕 Canis Major — Tech Debt
**Role**: Legacy code cleanup
**Triggers**: tech debt, todo, legacy, old code
**Output**: Debt reports, cleanup PRs

### 🐉 Hydra — CI/CD
**Role**: Pipeline automation
**Triggers**: ci, cd, pipeline, github actions
**Output**: Workflow files, pipeline configs
